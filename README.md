# Guardias Cloud v15

Gestión de guardias semanales con calendario, administración de usuarios, roles, comentarios de guardia, respuestas, reacciones y notificaciones.

La v15 incorpora el nuevo flujo de **Comentarios de guardia + chat en vivo**, tres roles (`admin`, `member`, `viewer`) y la nueva rotación real del equipo.

Consulta `README_GITHUB.md` para la documentación completa.
