# Guardias Cloud v11.4

Versión local/demo de Guardias Cloud.

Cambios principales:
- Las preferencias de notificación (24/48/72 horas) ahora están en Inicio, junto a Activar notificaciones.
- 24 horas antes aparece como opción recomendada.
- La preferencia se guarda localmente por dispositivo.
- La sección de Administración ya no contiene el selector de antelación; solo informa que la configuración se realiza desde Inicio.
- En Equipo, un integrante normal ve a todos como “Integrante”; el rol “Administrador” solo se muestra a quien tiene permisos de administrador.
- Se mantiene el funcionamiento local sin base de datos.
