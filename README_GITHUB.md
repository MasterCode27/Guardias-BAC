# Guardias Cloud v11.5 — Demo web

Versión local/demo para pruebas del equipo. No requiere base de datos: usa `localStorage` del navegador.

## Publicar en GitHub Pages

1. Sube el contenido de esta carpeta a un repositorio de GitHub.
2. En **Settings → Pages**, selecciona **Deploy from a branch**.
3. Selecciona la rama principal (`main`) y la carpeta `/ (root)`.
4. Guarda y espera a que GitHub Pages publique el sitio.
5. Comparte el enlace de GitHub Pages con los testers.
